# AI_DEMO

本仓库是一个**视觉位置识别（Visual Place Recognition, VPR）**领域的纯文档项目，系统梳理该方向从传统方法到预训练视觉基础模型的技术演进。

## 什么是视觉位置识别？

视觉位置识别（VPR）的任务是：**仅依靠相机图像，判断“这里我来过没有”**。机器人穿过楼宇、汽车行驶在街道、无人机飞越校园——当它们再次到达一个似曾相识的位置时，系统需要在不依赖 GPS、不依赖先验地图的前提下，从已采集的图像数据库中找回对应地点。

这看似简单，实则很难：同一地点在昼夜、雨雪、季节、视角变化下外观可能截然不同，系统仍须识别为同一位置。VPR 与定位、闭环检测、图像检索密切相关，是自主导航系统的核心能力之一。

## 典型应用场景

VPR 并非纯学术问题，而是支撑智能系统在真实世界中可靠运行的关键模块：

- **自主导航**：自动驾驶与移动机器人在 GPS 不可靠的室内、隧道、城市峡谷等环境中，通过视觉识别曾到访的道路或空间。
- **SLAM 与机器人闭环检测**：机器人检测重访地点以触发闭环，修正长期运行中累积的定位漂移。
- **无人机测绘与巡检**：多次飞行中识别同一区域，实现一致建图与基础设施监测。
- **增强现实（AR）**：跨会话将虚拟内容锚定到真实世界中的固定位置。
- **基于图像的地点检索**：在大型视觉数据库中，根据照片反查其拍摄位置。

更多背景介绍可参考 OpenCV 官方教程：[From Image Features to Visual Place Recognition](https://opencv.org/visual-place-recognition/)。
